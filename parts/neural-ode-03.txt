    <div class="card">
      <div class="h3">Training step 2 · Neural network predicts the rate of change</div>

      <p class="small">
        Before we continue, recall that
        \(z'(t)\)
        means the <strong>derivative of the state</strong>, or its instantaneous rate of change.
        If
        \(z(t)\)
        =
        (\(x(t)\),
        \(y(t)\)),
        then
      </p>

      <div class="card center math-cell">
        \[
        z'(t)=\bigl(x'(t),y'(t)\bigr).
        \]
      </div>

      <p class="small">
        For a moving object, this tells us the direction and speed of the motion at that instant.
      </p>

      <p class="small">
        We now use the neural network for the first time.
        It takes the current time and current state and predicts the current rate of change.
        Later, we will use this <strong>same neural network again</strong> at each new time.
      </p>

      <div class="card center math-cell" style="font-size:1.2em">
        \[
        (t,z(t))\longrightarrow f_\theta
        \longrightarrow \text{predicted }z'(t)
        \]
      </div>

      <p class="small">
        The diagram above shows the idea in words, while the equation below writes the same relationship mathematically.
      </p>

      <div class="card center math-cell" style="font-size:1.25em">
        \[
        z'(t)=f_\theta\bigl(t,z(t)\bigr).
        \]
      </div>

      <div class="card panel small">
        <strong>What is \(f_\theta\)?</strong><br>
        It is the neural network.
        Its job is simple: given the current \(t\) and \(z(t)\),
        it predicts the current rate of change
        \(z'(t)\).
        We reuse this same network throughout the trajectory.
      </div>

      <p class="small">
        At the starting time,
        \[
        z'(t_0)=f_\theta\bigl(t_0,z(t_0)\bigr).
        \]
        This is the first rate of change predicted by the neural network.
      </p>

    </div>

    <div class="card">
      <div class="h3">Training step 3 · ODE solver moves the state forward</div>

      <p class="small">
        The neural network and the ODE solver have different jobs.
      </p>

      <div class="grid two">
        <div class="card panel small">
          <strong>Neural network</strong><br>
          predicts the current rate of change
          \(z'(t)\).
        </div>
        <div class="card panel small">
          <strong>ODE solver</strong><br>
          uses that rate of change to estimate the next state.
        </div>
      </div>

      <p class="small">
        With Euler's method,
      </p>

      <div class="card center math-cell" style="font-size:1.12em">
        \[
        z_{n+1}\approx z_n+\Delta t\,f_\theta(t_n,z_n).
        \]
      </div>

      <p class="small">
        Here, \(\Delta t\) is a small time step.
        The result is a new state
        \(z_{n+1}\).
      </p>
    </div>

    <div class="card">
      <div class="h3">Training step 4 · Repeat the same cycle to build the trajectory</div>

      <p class="small">
        After the solver gives us a new state, we do <strong>the same thing again</strong>.
        We do not create a new neural network.
        We reuse the same
        \(f_\theta\) with the new state as input.
      </p>

      <div class="card center math-cell">
        \[
        z(t_0)\longrightarrow f_\theta\longrightarrow \text{ODE solver}
        \longrightarrow z(t_1)\longrightarrow f_\theta\longrightarrow \text{ODE solver}
        \longrightarrow z(t_2)\longrightarrow\cdots
        \]
      </div>

      <p class="small">
        At each new time, the input changes because the current state has changed,
        but the neural network itself is the same.
      </p>

      <div class="card panel small">
        <strong>Repeated cycle:</strong><br>
        current state
        → same neural network predicts the rate of change
        → ODE solver finds the next state
        → repeat
      </div>

      <p class="small">
        Repeating this cycle across the observation interval gives the predicted trajectory.
      </p>
    </div>

      </p>
